# Base Militaire - Wind Studio

Cette base de serveur FiveM a été créée par **Wind Studio**.

## 📖 Lisez la documentation avant d'installer

Toute l'installation et la configuration sont expliquées dans la documentation officielle :

👉 **https://wind-studio-1.gitbook.io/wind-studio-docs/**

Vous y trouverez :

* l'installation pas à pas ;
* l'import de la base de données ;
* la configuration de chaque script ;
* la liste des commandes et des touches ;
* les solutions aux problèmes les plus courants.

## En bref

1. Importez le fichier `wind_studio_base.sql` dans votre base de données.
2. Ouvrez le fichier `server.cfg` et remplissez les lignes marquées `## >>> À MODIFIER`.
3. Récupérez les scripts Wind Studio et les mappings sur le [Cfx Portal](https://portal.cfx.re/assets/granted-assets), puis placez-les dans leurs dossiers.
4. Démarrez votre serveur.

Chaque étape est détaillée dans la documentation.
